为单手键盘操作设计，鼠标只用于事后微调。

| 键 | 行为 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `L` / `J` | 加速 / 减速（1→2→4→8→16x） |
| `K` | 恢复 1x |
| `M` | 静音 / 取消静音 |
| `←` / `→` | ±5s（按住 `Shift` 为 ±30s） |
| `,` / `.` | 逐帧后退 / 前进 |
| `I` / `O` | 标入点 / 标出点 |
| `X` / `Delete` | 删除选中片段 |
| `Esc` | 关闭弹框，或取消未完成的入点 |
| `⌘/Ctrl+Z` | 撤销 |
| `⌘/Ctrl+O` | 打开文件 |
| `⌘/Ctrl+W` | 关闭当前文件 |
| `⌘/Ctrl+E` / `Enter` | 导出 |
| `⌘/Ctrl+,` | 设置 |

:::tip
标重叠了不必管——重叠的片段会自动合并成一段。
:::
