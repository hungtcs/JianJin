双层结构，共享同一份视图状态。

## 两条轨

**细节**（上）—— 可缩放轨，打点时盯的就是它。滚轮平移，`⌘/Ctrl`+滚轮缩放，
触控板双指捏合缩放。刻度尺下方的细刻度是**关键帧位置**。

**全片**（下）—— 整片地图，**只控制视口，不改播放进度**。绿块是已标片段，
蓝框是上方细节轨正在看的范围：

| 操作 | 行为 |
| --- | --- |
| 拖蓝框主体 | 平移细节轨 |
| 拖蓝框左右边缘 | 缩放细节轨 |
| 点 / 拖空白处 | 视口居中到指针并跟着拖 |

背景那层很淡的波形用来一眼找出静音段。播放位置是顶边的小三角——这里**不画竖线**：
两轨缩放不同，竖线永远对不齐，反而误导。

:::note
两条轨共享同一个视图控制器是刻意的。「播放跟随」与「用户手动平移」必须只有一个裁决点，
否则二者每帧互相覆盖，表现为抖动。
:::

## 片段编辑

鼠标移上去光标就会变，不用按下去试：

| 光标 | 位置 | 操作 |
| --- | --- | --- |
| ↔ | 片段边缘 | 拖动调整该端点 |
| ✋ | 片段内部 | 整体平移，**时长不变** |
| ✛ | 空白处 / 刻度尺 | 拖动 scrub |

刻度尺那一条不参与片段交互——它没有绘制片段，就不该能拖动片段。

点击右侧片段列表即**试看**：跳到起点播放，到终点自动暂停。

## 调整高度

播放区与底部之间有一条分隔条，上下拖动可调整时间轴高度。刻度尺与缩略图是固定高度，
**多出来的空间全部归波形**——只有它能从更高的轨道里真正获益。

## 播放跟随

播放时视图自动跟随播放头。**一旦手动平移或缩放，立即交出跟随权**，此后视图纹丝不动，
滚动查看时不会和自动跟随打架。

等播放头自己走进当前视野，跟随权无声收回——此刻视图无需移动，所以不会跳。
